# OpenAI plugin submission packet

This directory prepares Mentor Match for the OpenAI plugin review portal. It does not claim that developer identity, organization permissions, or publication approval have already been completed.

## Included materials

- `LISTING.md`: proposed public listing copy, links, availability, and starter prompts.
- `TEST_CASES.md`: seven positive, three out-of-scope negative, and one adversarial review case.
- `RELEASE_NOTES.md`: initial release notes.
- `../evals/cases.jsonl`: machine-readable behavioral cases and invariants.
- `../PRIVACY.md`, `../TERMS.md`, and `../SECURITY.md`: public policy and support material.

## Publisher actions still required

1. Publish this repository at `https://github.com/GPDdev/mentor-match`.
2. Verify the publisher identity and required workspace permission in the OpenAI submission portal.
3. Confirm the final supported-country selection and support readiness.
4. Upload the final Skill bundle, listing assets, prompts, test cases, and release notes.
5. Address review feedback, then explicitly publish the approved release.

The final uploaded bundle must be rebuilt from the same Git revision that is tagged for release.
