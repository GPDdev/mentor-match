## Interpret incomplete answers

- Treat the resume as evidence of past experience, not proof of future interests.
- Do not infer protected traits, financial capacity, nationality, or willingness to relocate.
- If priorities are prose rather than numbers, translate them into weights and show the translation before ranking.
- If institution scope is supplied, keep it hard unless the user labels it a preference.
- If the user supplies no search mode, use Standard.
- If output language is omitted, follow the user's current language.
- Ask follow-ups only when a missing answer affects eligibility, search boundaries, persistence consent, or a potentially costly decision.
