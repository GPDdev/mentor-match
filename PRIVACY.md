# Privacy Policy

Last updated: 2026-09-19

Mentor Match is a local-first Agent Skill published by GPDdev. This policy describes the behavior of the open-source plugin package itself. The AI product, browser, operating system, and websites used with the Skill may have their own privacy policies.

## Data Mentor Match may store

After one-time informed consent, Mentor Match may store the following in the user's selected local environment:

- complete resumes and supporting application files;
- normalized applicant profiles and preferences;
- application cases, search scopes, and ranking priorities;
- research reports, source links, candidate records, and search logs;
- pre-application drafts and refresh history;
- monitoring configuration and change reports.

The default directory is `~/.mentor-match/`. The user may configure another directory.

## Before storage

Mentor Match must disclose the resolved storage path, the categories of data saved, the local plain-file format, and the available export and deletion controls. Installation alone is not storage consent.

## Network use

Mentor Match instructs the host Agent to search public web sources. It must not place phone numbers, private email addresses, home addresses, identity numbers, full resume text, or other unnecessary personal data into web queries or external forms.

Opening a source page discloses ordinary request information to that site according to the site's own policies. Optional scholarly services may log IP addresses, query terms, or identifying headers under their policies.

## No plugin telemetry

The Mentor Match package contains no analytics, advertising, tracking pixel, bundled remote database, or background telemetry. It does not include an MCP server or transmit the local profile store to GPDdev.

## Local security

Stored data consists of local plain files. Its confidentiality depends on the user's device security, account permissions, backups, synchronization settings, and chosen directory. Users should not place the data root in a public repository or shared folder unless they intend to share its contents.

## Export, archive, and deletion

The included helper can list, export, archive, and permanently delete profiles and cases. Permanent deletion requires exact identifier confirmation. Local backups or third-party synchronization services may retain copies outside Mentor Match's control.

## Data minimization

Reports should repeat only personal information needed for the decision. Secrets, passwords, API keys, session cookies, and private messages must not be stored in Mentor Match artifacts.
